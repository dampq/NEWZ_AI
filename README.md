# NEWZ AI 📰

**Your World, In Perspective.**

NEWZ AI is a news web application that brings the latest headlines and AI briefings into one place. Explore stories by topic, search for headlines, and save articles to your personal account. Ask the AI assistant to summarize the news and help you understand the stories that matter.

## Features

- **Latest headlines:** Browse news from BBC News, with links to the original articles.
- **AI briefings:** Ask questions about the available headlines and get summaries powered by Google Gemini.
- **Personal library:** Create an account, save stories, and return to them later.
- **Topics and search:** Explore world news, business, technology, science, culture, and sports, or search for a headline.
- **Account tools:** Sign up, log in, log out, and reset your password through Supabase.
- **Responsive layout:** Read the news on desktop and mobile.

## Built with

JavaScript, HTML, CSS, Vite, Node.js, Express, Gemini API, and Supabase. Hosted on Render.

## Try the project

### [Open NEWZ AI](https://newz-ai.onrender.com)

Browse the latest headlines without signing in. Create an account or log in to save stories and use **Your AI briefing**. Try asking: “Summarize today’s headlines and include source links.” No installation, terminal, or personal API key is needed to use the website.

The first visit may take a little longer while the free hosting service wakes up. AI responses depend on Gemini availability and usage limits.
