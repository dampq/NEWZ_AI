# NEWZ AI

NEWZ AI is a news website that helps you explore the latest headlines and understand the stories behind them. Browse news by topic, save articles, and ask the AI assistant for a briefing.

**Visit the website: [newz-ai.onrender.com](https://newz-ai.onrender.com)**

## Features

- Latest headlines from BBC News
- News categories and headline search
- AI news briefings powered by Google Gemini
- Sign up, log in, and reset your password
- Save stories to your personal account
- Responsive design for desktop and mobile

## Built with

JavaScript, Vite, Node.js, Express, Supabase, and Google Gemini. Hosted on Render.

For local development and hosting instructions, see the [setup guide](docs/SETUP.md).
